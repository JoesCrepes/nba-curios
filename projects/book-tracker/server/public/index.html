Book Tracker — POC

Stateless validation only. Nothing here saves to a database — see the real app for that.

1. Search (Hardcover)

Validates the metadata source. Requires HARDCOVER_API_TOKEN to be set in this deployment's env vars.

2. Check library availability (Libby)

No card number or login needed — this is public catalog data. Library key is a best guess for DC Public Library (dclibrary, from their OverDrive URL) — edit if it turns out wrong.

3. Link a Libby account (optional)

Only needed to test the account-link auth flow itself — not required for availability checks above. In the Libby app: Settings → "Copy to another device" for an 8-digit code. Nothing is stored; the response just shows what your account's chip/sync returns.
